Política de privacidade

Última atualização: 3 de agosto de 2026

O CortaFlow é uma plataforma de gestão para barbearias. Esta política explica quais dados são tratados, por que são usados e quais escolhas estão disponíveis para você.

1. Dados tratados

Podemos tratar dados de cadastro e acesso, informações da barbearia, profissionais, clientes, serviços, agendamentos, registros financeiros e dados técnicos necessários para segurança e funcionamento da plataforma.

2. Como usamos os dados

  • Para criar e proteger contas;
  • Para organizar agendamentos, clientes, equipe e financeiro;
  • Para enviar confirmações e notificações solicitadas;
  • Para processar assinaturas e pagamentos por provedores especializados;
  • Para prevenir fraude, corrigir falhas e melhorar o serviço.

3. Compartilhamento

Não vendemos dados pessoais. Compartilhamos somente o necessário com fornecedores que apoiam a operação, como hospedagem, e-mail, pagamentos e mensagens, sempre conforme a finalidade do serviço.

4. Retenção e segurança

Mantemos os dados pelo tempo necessário à prestação do serviço, às obrigações legais e à segurança da plataforma. Usamos autenticação, controle de acesso, conexões protegidas e senhas armazenadas de forma segura. Nenhuma medida tecnológica elimina todos os riscos.

5. Seus direitos

Você pode solicitar confirmação de tratamento, acesso, correção, atualização ou exclusão dos dados, observadas as obrigações legais e os registros necessários à segurança.

6. Contato

Para dúvidas ou solicitações sobre privacidade, escreva para cortaflow178@gmail.com.
